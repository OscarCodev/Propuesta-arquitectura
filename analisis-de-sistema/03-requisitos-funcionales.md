# Requisitos funcionales

Los requisitos funcionales describen las funciones y comportamientos que el sistema Closer debe proporcionar para satisfacer las necesidades identificadas en las historias de usuario.

## Requisitos funcionales

| ID | Requisito funcional |
|---|---|
| **RF01** | El sistema debe permitir registrar usuarios e iniciar sesión mediante correo electrónico o proveedores OAuth. |
| **RF02** | El sistema debe permitir configurar el perfil comercial del usuario. |
| **RF03** | El sistema debe permitir registrar el producto o servicio que se utilizará en una simulación. |
| **RF04** | El sistema debe permitir crear y editar perfiles de prospectos o buyer personas. |
| **RF05** | El sistema debe permitir generar escenarios y perfiles de prospectos con apoyo de Inteligencia Artificial. |
| **RF06** | El sistema debe permitir seleccionar la etapa de venta, personalidad y voz del prospecto simulado. |
| **RF07** | El sistema debe permitir realizar conversaciones bidireccionales por voz con el prospecto IA en tiempo real. |
| **RF08** | El sistema debe permitir silenciar el micrófono y finalizar una sesión de práctica. |
| **RF09** | El sistema debe mostrar indicadores de audio y transcripción durante la llamada. |
| **RF10** | El sistema debe generar una evaluación posterior a la llamada con métricas de desempeño. |
| **RF11** | El sistema debe mostrar un gráfico de radar de competencias comerciales. |
| **RF12** | El sistema debe calcular métricas de conversación como tiempo de habla, escucha y duración de sesión. |
| **RF13** | El sistema debe generar recomendaciones y retroalimentación mediante un coach de ventas automatizado. |
| **RF14** | El sistema debe permitir consultar la transcripción completa y analizada de una sesión. |
| **RF15** | El sistema debe permitir guardar y reutilizar perfiles de prospectos. |
| **RF16** | El sistema debe permitir consultar el historial de sesiones y la evolución del usuario. |
| **RF17** | El sistema debe permitir eliminar sesiones y perfiles guardados. |
| **RF18** | El sistema debe mostrar los límites de uso del plan y permitir consultar opciones de suscripción. |
| **RF19** | El sistema debe proporcionar un medio para enviar consultas, feedback o reportes de soporte. |
