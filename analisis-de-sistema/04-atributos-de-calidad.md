# Atributos de calidad

Los atributos de calidad establecen las características no funcionales que debe cumplir el sistema Closer para garantizar una experiencia adecuada durante las simulaciones de voz, el procesamiento de resultados y el almacenamiento de información.

## Escenarios de calidad

| ID | Atributo de calidad | Escenario de calidad |
|---|---|---|
| **AC01** | **Rendimiento** | La conversación por voz debe procesarse con una latencia suficientemente baja para mantener una interacción fluida y evitar pausas que rompan el realismo de la simulación. |
| **AC02** | **Disponibilidad** | La plataforma debe permanecer disponible para que los usuarios puedan iniciar sesiones de práctica y consultar sus resultados cuando lo requieran. |
| **AC03** | **Escalabilidad** | El sistema debe poder incrementar la cantidad de sesiones simultáneas sin afectar significativamente la experiencia de los usuarios. |
| **AC04** | **Seguridad** | Los datos de usuarios, sesiones, transcripciones y credenciales deben estar protegidos frente a accesos no autorizados. |
| **AC05** | **Mantenibilidad** | La solución debe organizar sus componentes de forma modular para permitir cambios en la lógica de negocio, modelos de IA e integraciones sin afectar innecesariamente otras partes del sistema. |
| **AC06** | **Usabilidad** | La configuración de escenarios, inicio de simulaciones y revisión de resultados debe ser comprensible y requerir pocos pasos para el usuario. |
| **AC07** | **Interoperabilidad** | El sistema debe poder comunicarse con servicios externos de IA, autenticación, pagos y notificaciones mediante interfaces bien definidas. |
