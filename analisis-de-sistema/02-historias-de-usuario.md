# Historias de usuario

En esta sección se presentan las historias de usuario principales del sistema Closer, describiendo las funcionalidades desde la perspectiva de los usuarios que interactúan con la plataforma.

| ID | Historia de usuario |
|---|---|
| **HU01** | Como usuario, quiero registrarme e iniciar sesión, para acceder a mi espacio de entrenamiento. |
| **HU02** | Como usuario nuevo, quiero configurar mi perfil comercial, para adaptar las simulaciones a mi contexto profesional. |
| **HU03** | Como vendedor, quiero definir el producto o servicio que vendo, para que la IA comprenda el contexto de la simulación. |
| **HU04** | Como vendedor, quiero configurar un buyer persona, para practicar con un prospecto parecido a mis clientes reales. |
| **HU05** | Como usuario, quiero generar automáticamente un escenario con IA, para iniciar una práctica rápidamente. |
| **HU06** | Como vendedor, quiero seleccionar la etapa de la llamada y personalidad del prospecto, para entrenar situaciones específicas. |
| **HU07** | Como usuario, quiero seleccionar una voz para el prospecto virtual, para obtener una experiencia de práctica más variada. |
| **HU08** | Como vendedor, quiero conversar por voz con el prospecto IA en tiempo real, para simular una llamada comercial realista. |
| **HU09** | Como usuario, quiero silenciar o finalizar una llamada, para controlar la sesión de práctica. |
| **HU10** | Como usuario, quiero visualizar indicadores de audio y transcripción durante la sesión, para verificar que el sistema reconoce correctamente la conversación. |
| **HU11** | Como vendedor, quiero visualizar un gráfico de radar de mis habilidades, para identificar fortalezas y áreas de mejora. |
| **HU12** | Como vendedor, quiero conocer métricas de habla y escucha, para evaluar mi comportamiento durante la conversación. |
| **HU13** | Como vendedor, quiero recibir recomendaciones del coach IA, para corregir errores en futuras llamadas. |
| **HU14** | Como usuario, quiero revisar la transcripción analizada de la sesión, para identificar momentos importantes de la conversación. |
| **HU15** | Como usuario, quiero guardar perfiles de prospectos, para reutilizarlos en nuevas simulaciones. |
| **HU16** | Como usuario, quiero consultar mi historial de sesiones, para observar mi evolución en el tiempo. |
| **HU17** | Como usuario, quiero eliminar sesiones o perfiles guardados, para mantener organizada mi información. |
| **HU18** | Como usuario, quiero conocer mis límites de uso y opciones de plan, para continuar practicando cuando alcance mi cuota. |
| **HU19** | Como usuario, quiero acceder a un medio de soporte, para reportar problemas o enviar comentarios. |
